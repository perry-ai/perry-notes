# 前端生产问题排查标准流程(SOP)

## 1. 问题分类
### 1.1 交互类问题
- UI显示异常
- 操作无响应
- 动画卡顿
- 表单验证失败

### 1.2 业务逻辑问题
- 数据展示错误
- 流程中断
- 状态不一致
- 权限控制失效

### 2.2 数据流分析
1. API请求检查
   - 请求参数
   - 响应数据
   - 状态码
2. 本地数据处理
   - Redux/Vuex状态
   - 组件内部状态
3. 数据转换逻辑

1. 相关组件定位
2. 生命周期钩子检查
3. 事件处理逻辑
4. 异步操作流程
